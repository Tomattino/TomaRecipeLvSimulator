# 🍅 料理レベ上げシミュ（あるふぁ版）

ポケモンスリープの **料理レベル上げに必要な調理回数** をシミュレーションする Web ツールです。
「あと何回作れば目標レベルに届くか」「そのために食材は何個いるか」を、自分のプレイ状況に合わせて計算できます。

🔗 **[今すぐ使う](https://tomattino.github.io/TomaRecipeLvSimulator/)**

> ⚠️ **あるふぁ版です。** 開発中のため動作の保証はありません。予告なく仕様変更・機能追加を行うことがあります。

---

## できること

- **調理回数シミュレーション** … 開始レベル → 目標レベルに必要な調理回数を計算
- **ボーナス対応** … フィールドボーナス・イベントボーナスを反映
- **1回ごとの条件設定** … 日曜（×3）・大成功（×2）を調理1回単位でオン / オフ
- **エナジーの手入力上書き** … 実測値との差分を補正したいときや、追加食材を個別入力する代わりにまとめて調整したいときに利用
- **食材別の必要数** … 目標達成までに必要な食材を種類ごとに算出
- **レベル別の内訳** … 各レベルの必要 EXP・繰り越しを確認
- **履歴機能** … 直近の状態を自動保存し、名前を付けて保存・読み戻し

> 履歴データはブラウザの localStorage に保存され、**この端末の中だけ** に保持されます。サーバーには送信されません。プライベートブラウズなどでは保存されない場合があります。
